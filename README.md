# Elon Musk – Interactive Biography Website

This project is a multi-page, fully responsive website dedicated to presenting the life, businesses, innovations, and influence of Elon Musk.

Built using HTML, CSS, and responsive design techniques, it showcases structured content, animations, and modern UI components to offer an engaging user experience.

## 🔥 Features

- **Home Page:** Dynamic hero section, quick navigation, and curated news cards. See `pages/index.html`.
- **Biography Page:** Timeline-style layout highlighting Elon Musk's early life, education, and evolution. See `pages/bio.html`.
- **Business Page:** Detailed overview of his major companies (Tesla, SpaceX, Neuralink, PayPal…). See `pages/business.html`.
- **Innovation Page:** Focus on Starlink, autonomous driving, and key quotes presented with a slider system. See `pages/innovation.html`.
- **Gallery Page:** Visual sliders showcasing milestones and dreams of Elon Musk. See `pages/gallery.html`.

- Fully responsive navigation (desktop + mobile burger menu).
- Custom CSS styling with multiple design themes for each page.
- Clean code structure and reusable layout components.

## 🛠️ Technologies Used

- HTML5
- CSS3 (flexbox, grid, custom animations)
- Responsive Web Design
- Image sliders implemented using CSS only

## 🎯 Project Goals

- Practice multi-page website architecture.
- Improve front-end design skills.
- Build UI components (sliders, navigation, cards, banners) without JavaScript.
- Create a visually appealing educational website.

## View Locally

1. Clone the repository or download the ZIP.
2. Open `pages/index.html` in your browser (or the page you want to view).

No build steps or package managers are required — this is a static site.

## Deploying (GitHub Pages)

You can publish the site using GitHub Pages:

1. Go to the repository on GitHub: `https://github.com/yassinedache/Elon-Musk-biographie`.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose the branch `master` and the folder `/ (root)` (or select `/pages` if you move the site there) and save.
4. GitHub will provide a URL where the site is published (may take a minute).

Alternatively, create a `gh-pages` branch and push the built files there for Pages to serve.
